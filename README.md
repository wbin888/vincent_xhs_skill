# vincent-xhs-cover

小红书爆款封面 & 高转化招生海报**提示词生成 Skill**，内置 **20 种视觉风格**。

用编号选择题一步步问清需求，自动读取参考相片色调、提炼文案重点，最后输出一段可以直接复制给生图模型（Nano Banana / GPT-4o / 即梦 / Flux / Midjourney）的完整提示词。

## 能做什么

| 体系 | 风格 | 适合 |
|---|---|---|
| 经典大字抠图封面 | 1–8 | AI 工具教程、效率工作流、产品测评、科普、种草 |
| 课程招生海报 | 9–15 | 私教、瑜伽、普拉提、团课、训练营、教培招生 |
| 通用版式 | 16–20 | 手绘、纯文本、简约、贴图、对比，封面与海报通用 |

**核心能力**

- **参考相片色调统一**：先识别人物服装色、光影冷暖与主色相，背景、卡片、字色都围绕它配色，避免抠图感。
- **文案重点 4 层提炼**：主标题（4–10 字）+ 高亮词/大数字 + 3 条重点（每条 4–8 字）+ 底部 CTA。
- **根据图片和文案自动推荐风格**：综合参考照特征（服装、场景、色调、素材数量）与文案类型，给出 Top 3 推荐及理由；也可以从 20 种风格中自选。
- **一题一问，全编号选择**：已提供的信息自动跳过；第 3 问可选 `0` 一键套用当前风格最佳预设，快速出图。
- **出图前 8 项复核**：色调、文案层级、3:4 比例、五官不遮挡、手部结构、黄色统一 `#FDFFA7`、素材分工、零占位符。
- **横版延展**：3:4 定稿后，可重构为 4:3 / 16:9 左右分栏横版（公众号、朋友圈、B 站）。

## 使用流程

```text
① 发图片 + 文案 → ② 自动推荐 Top 3 风格（或自选 1–20）→ ③ 动作 → ④ 素材用途
→ ⑤ 背景 → ⑥ 字体 → ⑦ 字色 → ⑧ 提炼重点 & 选标题 → 输出提示词
```

第 2 步回复 ⭐ 编号或“你定”即采用第一推荐；想要别的风格，直接回复 1–20 任一编号。首条消息就附上图片、文案或指定风格，会自动跳过对应步骤。

## 目录结构

```text
vincent-xhs-cover/
├── SKILL.md                 # 核心：铁律、风格推荐规则、8 步问答、复核清单、输出格式（约 15KB）
├── agents/openai.yaml       # Codex / OpenAI 展示信息
└── references/styles/       # 20 种风格的视觉特征 + 提示词模板，选定后按需读取
    ├── 01-big-title-top.md
    ├── ...
    └── 20-before-after.md
```

模板按风格拆成独立文件，每次只加载选中的那一个，`SKILL.md` 从 108KB 精简到约 15KB，响应更快、上下文更省。

## 安装

把整个 `vincent-xhs-cover` 目录（**包含 `references/`**）复制到 skills 目录：

```bash
# Codex
cp -R vincent-xhs-cover ~/.codex/skills/

# 通用 Agent Skills 目录
cp -R vincent-xhs-cover ~/.agents/skills/
```

> 从旧版本升级：需重新复制一次，否则缺少 `references/styles/` 会导致无法读取风格模板。

## 设计规范

- 默认 **3:4 竖版**，定稿后可扩展 4:3 / 16:9。
- 真人出镜，以图 1 保持五官一致；风格 17 可不出镜。
- 主标题超大、短促，移动端一眼可读。
- 黄色统一使用柔和浅黄 `#FDFFA7`，避免刺眼柠檬黄或偏橙黄。
- 文字不遮挡眼睛和嘴巴，重要元素全部位于安全区内。
