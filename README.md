# vincent-xhs-cover

Vincent 小红书爆款封面提示词生成 Skill（**13 种视觉风格全能增强版**）。

本项目基于 `atutun-xhs-cover` 的单选问答交互流进行深度重构与扩充，用于把文章、选题、产品测评、AI 工具教程、效率方法、播客推荐、个人经验、深度思考与好物盘点等内容，整理成可直接交给图片生成模型使用的 **3:4 竖版小红书封面提示词**。

在保留原版 **8 种经典高点击大字抠图风格**的基础上，新增扩充了 **5 种跨视觉美学爆款风格**（共 **13 种风格**，涵盖苹果极简杂志风、备忘录手写便签风、多巴胺高饱和插画风、醒目大字报纯享风、Bento 卡片网格风），所有风格均统一支持图 1 真人参考图出镜与人物一致性保持。

## 适用场景

- AI 工具教程、部署上手封面
- 产品横评、榜单与多维对比封面
- 效率工作流与全栈工具箱盘点封面
- 小白科普问答与深度行业认知封面
- 播客、资源、好物种草推荐封面
- 读书笔记、干货复盘与避坑指南封面
- 个人经验、方法论与重磅观点宣言封面


## 核心亮点与升级优化

相比原版单选流，本 Skill 进行了全方位的工程化升级：

1. **13 种风格全覆盖 + 智能路由表**：涵盖经典 8 种高点击大字抠图风与 5 种跨视觉美学热门风（苹果杂志、备忘录便签、多巴胺插画、街头大字报、Bento 网格），并内置**选题 → 风格智能推荐路由表**。
2. **“极速一键预设”与“精细定制”双轨体验**：
   - 第 1 问支持选 `0. 交给模型智能推荐`。
   - 第 3 问支持选 `0. ⚡ 一键采用当前风格全套最佳视觉预设`，选完人物、素材和标题即可极速出词，免去逐题选背景/字体/配色的繁琐；同时也完整保留 11–12 项精细单选供深度定制。
3. **主页固定配色截图保持**：第 7 问支持上传过往封面截图，自动提取标题主色、关键词强调色和描边逻辑，保持博主小红书主页视觉统一。
4. **7 项出图前强制质量复核**：内置比例锁死（防止横向参考图带偏 3:4 竖版画幅）、五官防遮挡、手部解剖结构约束、黄色统一 `#FDFFA7` 色号铁律、零占位符残留检查。
5. **一鱼多吃横版扩展（4:3 & 16:9）**：默认先做 3:4 竖版小红书封面；定稿后可一键重构成左右分栏的 4:3 和 16:9 横版封面提示词（适配公众号首图、B 站、YouTube、X/Twitter）。

## 使用流程

Skill 会按顺序向用户提问，并且**一次只问一个编号选择题**（已提供的信息会自动跳过）：

1. **选择封面风格（0 智能推荐 + 13 种风格）**：涵盖经典大字抠图风（1–8）与跨美学热门风（9–13）。
2. **上传人物参考图（图 1）**：全部 13 种风格统一强制要求上传真人参考图以保证人物一致性。
3. **选择人物表情和动作（支持 `0. 一键套用当前风格全套最佳视觉预设` + 12 种动作）**：涵盖震惊、点赞、指向、托腮、举拳、讲解，以及杂志松弛抱胸、拍立得歪头微破框、多巴胺跳跃欢呼、大字报严肃比“停”、Bento 侧身破框互动等专属姿态。
4. **选择额外素材图及呈现方式（4 选 1 + 8 种用途呈现）**：支持贴纸卡片、教程证据、苹果毛玻璃悬浮内嵌、曲别针/和纸胶带便签贴图、复古波普弹窗、Bento 独立子卡片等。
5. **选择背景色调（11 选 1，自动高亮当前风格推荐项）**：包含暖光室内、黑灰科技、深色工具墙、苹果银白毛玻璃、iOS 备忘录方格纸、多巴胺糖果撞色、先锋报刊黑/白高反差底、Bento 磨砂矩阵底等。
6. **选择字体风格（11 选 1，自动高亮当前风格推荐项）**：包含综艺超粗黑、漫画爆款字、现代无衬线+英文杂志刊头、备忘录粗黑+马克笔手写体、3D 波普泡泡体、街头特粗压缩黑体、Apple SF 仪表盘体等。
7. **选择字体颜色效果（12 选 1，支持上传过往封面截图保持主页配色）**：包含柔和浅黄 `#FDFFA7` + 粗黑描边、深炭黑 + 克莱因蓝/爱马仕橙胶囊高亮、浓黑墨水字 + `#FDFFA7` 荧光笔涂抹底条、多巴胺拼色 + 3D 硬阴影、大字报红白黑/黄黑反差、Bento 分区配色等。
8. **选择最终封面标题（4 选 1）**：结合所选风格的专属语感生成 3 个差异化候选标题供一键选择。

收集完信息并通过内部 7 项复核后，Skill 会输出可直接复制使用的封面提示词，并支持按需延展 4:3 / 16:9 横版构图。

## 13 种封面风格一览

### 体系一：经典高点击大字抠图体系（风格 1–8）
1. **爆款大字压顶风** — 顶部超大标题压住画面，人物居中，适合强钩子标题
2. **巨字拆分冲击风** — 2–4 个核心大词拆开放满画面，适合概念/身份/能力类主题
3. **小白科普问答风** — 黑灰科技海报或真实室内背景，问号和解释感，适合“什么是/怎么理解”
4. **教程清单风** — 绿色勾选清单 + 步骤感，适合安装、部署、上手教程
5. **产品测评榜单风** — 大数字、箭头、维度标签，适合横评、榜单、测评
6. **种草推荐风** — 人物点赞或推荐姿势，emoji 和温暖背景，适合资源/播客/工具推荐
7. **贴纸拼贴入门风** — 人物 + 小卡片 + 产品图标 + 贴纸，适合“入门/搭建/组合”
8. **黑底效率工作流风** — 深色背景 + Logo 墙 + 清单，适合工作法、效率流、工具组合

### 体系二：跨视觉美学小红书热门体系（风格 9–13）
9. **苹果极简杂志风** — 高级灰白/毛玻璃悬浮卡、呼吸感排版与杂志刊头，适合审美科技、深度认知、质感好物
10. **备忘录手写便签风** — 纸质肌理/备忘录方格、拍立得人物贴画、`#FDFFA7` 荧光马克笔涂抹高亮，适合干货总结、走心笔记、避坑复盘
11. **多巴胺高饱和插画风** — 明快高饱和撞色色块、波普几何贴纸与手绘涂鸦线条，适合创意玩法、副业灵感、生活黑客
12. **醒目大字报纯享风** — 街头海报级巨型字块占满版面、红白黑/黄黑强反差与人物破格穿插，适合重磅观点、行业揭秘、必看预警
13. **Bento 卡片网格风** — Apple 发布会式模块化圆角卡片矩阵（Bento Grid），分格展示核心指标与人物主卡，适合全栈工具箱、年度盘点、多维攻略

## 设计规范

- 固定 **3:4 竖版**小红书封面比例（定稿后支持重构成 4:3 与 16:9 横版）。
- 全风格**真人出镜**（基于图 1 保持五官与人物一致性），人物通常占画面 32%–50%。
- 主标题必须超大、清晰、短促，确保移动端信息流一眼可读。
- 凡使用黄色系（标题填充、关键词、底板、色块、横幅、荧光马克笔），统一指定为柔和浅黄色 `#FDFFA7`，避免刺眼柠檬黄或偏橙黄。
- 重要文字、人物脸部（眼睛和嘴巴）及核心模块内容绝不超出安全区，文字绝不遮挡五官。
