# vincent-xhs-cover

Vincent 小红书爆款封面 & 高转化招生海报提示词生成 Skill（**20 种视觉风格全能版**）。

本项目基于 `atutun-xhs-cover` 的单选问答交互流进行深度重构与扩充，分为三大核心视觉矩阵（共 **20 种风格**）：
1. **经典高点击大字抠图体系（风格 1–8）**：用于 AI 工具教程、效率工作流、产品测评榜单、科普问答、播客与好物种草等干货内容封面。
2. **高转化课程 / 瑜伽 / 普拉提 / 训练营招生海报体系（风格 9–15）**：将 7 种高审美视觉语言（苹果极简杂志风、备忘录便签课表风、多巴胺活力团课风、街头大字报早鸟特训风、Bento 网格全维课程风、自然疗愈瑜伽风、精准体态普拉提私教风）全面升级为**具备完整“主标题 + 导师形象 + 3 大课程卖点/课表 + 报名福利行动召唤（CTA）”转化结构的招生海报**。
3. **万能通用排版与视觉表达体系（风格 16–20）**：新增 **手绘版、纯文本版、简约版、贴图版、对比版** 5 大高频通用版式，干货内容封面与课程招生海报双栖通用。

所有 20 种风格均强制执行 **“先看参考相片色调以确保整张画面色彩和谐统一”** 与 **“深度提炼文案核心重点（主标题 + 高亮词 + 3 大精炼重点 + 底部收尾/CTA）”**。

## 适用场景

- **瑜伽馆小班招生、冥想音疗、身心工作坊、教培认证招募海报**
- **普拉提器械（Reformer）私教、体态矫正、产后修复、暴汗燃脂团课招生海报**
- **1v1 名师私教课、周度/月度课表发布、打卡陪跑营、早鸟特惠大促招生海报**
- **手绘知识笔记、纯文字大字金句、极简留白美学、多图剪报贴图合集、Before/After 前后对比图**
- AI 工具教程、部署上手、产品横评榜单、效率工作流与好物种草推荐封面

## 包含内容

```text
vincent-xhs-cover/
  SKILL.md
  agents/
    openai.yaml
  references/
    styles/
      01-big-title-top.md
      ...
      20-before-after.md
```

- `SKILL.md`：精简核心（约 15KB）：核心铁律、智能推荐路由表、8 步交互式单选题流程（支持一键预设）、出图复核清单与输出格式。
- `references/styles/`：**20 种风格各自独立的视觉特征与提示词模板**，用户选定风格后才按需读取，避免每次加载全部模板、节省上下文。
- `agents/openai.yaml`：OpenAI/Codex 侧的展示名、简介和默认调用提示。

## 安装方式

把 `vincent-xhs-cover` 目录复制到 Codex / Claude / Copilot skills 目录：

```bash
# Codex
cp -R vincent-xhs-cover ~/.codex/skills/

# 通用 Agent Skills 目录
cp -R vincent-xhs-cover ~/.agents/skills/
```

安装后可以通过下面的方式调用：

```text
$vincent-xhs-cover
```

或直接描述需求，例如：

```text
用 vincent-xhs-cover 帮我生成一张普拉提器械私教招生小红书海报提示词。
```

## 核心亮点与升级优化

1. **全风格先看参考相片色调，整张画面色彩和谐统一**：
   - 收到图 1 参考照（及图 2/3 素材）后，第一时间识别并提取参考相片的**服装颜色、肤色冷暖、原片光影色温与主色相**。
   - 20 种风格全部内置`【参考相片色调和谐基准】`，让背景色系、卡片底色、手绘水彩色盘、贴图边框、双栏对比色温与人物边缘环境受光围绕参考相片色调做同色系/邻近色和谐延展，杜绝生硬抠图感与色彩打架。
2. **全风格深度提炼文案重点，4 层视觉重点一秒抓人**：
   - 自动将长篇干货或繁杂课程介绍去芜存菁，提炼为 **① 主标题视觉锤（4–10 字） + ② 灵魂高亮关键词/大数字（`#FDFFA7` 或和谐主题色放大） + ③ 3 条精炼核心重点/课程卖点/对比标签（每条 4–8 字） + ④ 底部收尾金句/报名行动召唤（CTA）**。
3. **三大体系 20 款全能风格**：涵盖 1–8 经典干货大字抠图风、9–15 高转化课程/运动招生海报风、16–20 万能通用排版风（手绘版、纯文本版、简约版、贴图版、对比版）。
4. **“极速一键预设”与“精细定制”双轨体验**：
   - 第 1 问支持选 `0. 交给模型智能推荐`。
   - 第 3 问支持选 `0. ⚡ 一键采用当前风格全套最佳视觉预设（自动根据参考相片色调协调背景/字体/配色，并提炼文案重点直接选标题）`。
   - 第 5 问（背景）与第 7 问（字色）均提供 `0. 🎨 根据参考相片色调自动和谐配比`。
5. **主页固定配色截图保持**：第 7 问支持上传过往封面/海报截图，自动提取标题主色、关键词强调色和描边逻辑，保持主页视觉统一。
6. **8 项出图前强制质量复核**：内置参考相片色调和谐度复核、文案重点层级复核、比例锁死（防止横向参考图带偏 3:4 竖版画幅）、五官防遮挡、手部与运动肢体解剖结构约束、黄色统一 `#FDFFA7` 色号铁律、零占位符残留检查。
7. **一鱼多吃横版扩展（4:3 & 16:9）**：默认先做 3:4 竖版小红书封面/招生海报；定稿后可一键重构成左右分栏的 4:3 和 16:9 横版海报提示词（适配公众号首图、社群招生横图、朋友圈、B 站）。

## 20 种风格一览

### 体系一：经典高点击大字抠图体系（风格 1–8，适合干货/测评/教程）
1. **爆款大字压顶风** — 顶部超大标题压住画面，人物居中，适合强钩子标题
2. **巨字拆分冲击风** — 2–4 个核心大词拆开放满画面，适合概念/身份/能力类主题
3. **小白科普问答风** — 黑灰科技海报或真实室内背景，问号和解释感，适合“什么是/怎么理解”
4. **教程清单风** — 绿色勾选清单 + 步骤感，适合安装、部署、上手教程
5. **产品测评榜单风** — 大数字、箭头、维度标签，适合横评、榜单、测评
6. **种草推荐风** — 人物点赞或推荐姿势，emoji 和温暖背景，适合资源/播客/工具推荐
7. **贴纸拼贴入门风** — 人物 + 小卡片 + 产品图标 + 贴纸，适合“入门/搭建/组合”
8. **黑底效率工作流风** — 深色背景 + Logo 墙 + 清单，适合工作法、效率流、工具组合

### 体系二：高转化课程 / 瑜伽 / 普拉提 / 训练营招生海报体系（风格 9–15）
9. **苹果极简杂志风·名师私教招生海报** — 高级银白/暖灰渐变、毛玻璃课程大纲悬浮卡、导师商业杂志肖像与底部私教预约胶囊，适合高客单价 1v1 私教、主理人大师课、精品教培招募
10. **备忘录手写便签风·课表大纲招生海报** — 备忘录方格纸肌理、拍立得导师贴画、`#FDFFA7` 荧光笔划重点课程名、手写勾选周课表与朱红笔名额提醒，适合周/月课表发布、零基础入门班、打卡陪跑营招生
11. **多巴胺高饱和插画风·活力团课招生海报** — 高饱和糖果撞色、双层波普教练贴画、3D 立体大字与 `#FDFFA7` 锯齿爆炸福利贴，适合燃脂暴汗团课、尊巴/有氧舞蹈、周末活力训练营招生
12. **醒目大字报纯享风·限时特训招生海报** — 街头海报级巨型痛点/特惠大字占满版面、黑黄 `#FDFFA7` / 红白黑强反差、导师破格穿插与底部早鸟倒计时横幅，适合周年庆大促、早鸟立减、痛点暴击特训营招生

14. **自然疗愈呼吸感·瑜伽/冥想招生海报** — 晨光百叶窗原木绿植瑜伽馆、燕麦米白与鼠尾草绿自然光影、导师舒展体式、3 大疗愈卖点亚麻卡 + 底部 `#FDFFA7` 早鸟限额招募横幅，适合流瑜伽、阴瑜伽、冥想音疗、周末工作坊招生
15. **精准体态美学·普拉提私教招生海报** — 核心床（Reformer）现代明亮场馆、人体工学流线美学弧线、3 大部位改善指标卡（天鹅颈直角肩 / 核心收紧 / 骨盆正位）+ 底部限时私教体验预约栏，适合普拉提器械私教、产后修复、体态矫正招生

### 体系三：万能通用排版与视觉表达体系（风格 16–20，干货封面与招生海报双栖通用）
16. **手绘版（温润手绘插画·涂鸦重点笔记风）** — 水彩/马克笔手绘插画元素、涂鸦虚线重点框、手绘引导线与真人虚实结合，手绘色盘顺应参考相片色调，适合知识图解、动作要点拆解、亲和力课程招生
17. **纯文本版（高审美纯文字排版·重点金句直出风）** — 提取参考相片色调作为高级底板，靠殿堂级杂志字体排版、字号层级反差、`#FDFFA7` 荧光重点块与 `01/02/03` 三大精炼重点取胜（可纯文字无人物，或仅角落嵌极简小头像），适合金句观点、干货提纲、课程核心通知
18. **简约版（极简留白呼吸感·克制高级美学风）** — 40%+ 大面积高级留白、同色系温润光影融合、无描边干净排版与 3 个极简短词重点，适合高审美生活方式、深度干货、高端瑜伽/普拉提/私教工作室海报
19. **贴图版（多图剪报杂志拼贴·高密度手账贴图风）** — 真人主图 + 3–4 张带加厚白边/胶带/立体阴影的实拍剪报贴图（场馆/产品/动作分解/学员反馈）层叠拼贴，统一全图色温并实现“一图一重点角标”，适合多图合集、多维展示招生
20. **对比版（Before/After 强反差双栏对比·痛点逆袭风）** — 左右或上下双栏鲜明反差（`❌ 痛点/错误/改善前` VS `✅ 逆袭/正确/改善后`），冷暗痛点侧与温暖高亮蜕变侧形成强烈视觉冲击，适合体态矫正前后对比、效率前后对比、红黑榜避坑

## 设计规范

- 固定 **3:4 竖版**小红书封面/招生海报比例（定稿后支持重构成 4:3 与 16:9 横版）。
- 全风格**真人出镜**（基于图 1 保持五官与人物一致性），人物通常占画面 34%–50%。
- 主标题必须超大、清晰、短促，确保移动端信息流一眼可读。
- 凡使用黄色系（标题填充、关键词、底板、色块、招生横幅、荧光马克笔、爆炸福利贴），统一指定为柔和浅黄色 `#FDFFA7`，避免刺眼柠檬黄或偏橙黄。
- 重要文字、人物脸部（眼睛和嘴巴）及核心模块内容绝不超出安全区，文字绝不遮挡五官。
