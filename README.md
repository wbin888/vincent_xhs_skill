# vincent-xhs-cover

Vincent 小红书爆款封面 & 高转化招生海报提示词生成 Skill（**15 种视觉风格全能版**）。

本项目基于 `atutun-xhs-cover` 的单选问答交互流进行深度重构与扩充，分为两大核心视觉矩阵（共 **15 种风格**）：
1. **经典高点击大字抠图体系（风格 1–8）**：用于 AI 工具教程、效率工作流、产品测评榜单、科普问答、播客与好物种草等干货内容封面。
2. **高转化课程 / 瑜伽 / 普拉提 / 训练营招生海报体系（风格 9–15）**：将 7 种高审美视觉语言（苹果极简杂志风、备忘录便签课表风、多巴胺活力团课风、街头大字报早鸟特训风、Bento 网格全维课程风、自然疗愈瑜伽风、精准体态普拉提私教风）全面升级为**具备完整“主标题 + 导师形象 + 3 大课程卖点/课表 + 报名福利行动召唤（CTA）”转化结构的招生海报**。

所有 15 种风格均统一支持图 1 真人（博主/主讲导师/教练）参考图出镜与人物一致性保持。

## 适用场景

- **瑜伽馆小班招生、冥想音疗、身心工作坊、教培认证招募海报**
- **普拉提器械（Reformer）私教、体态矫正、产后修复、暴汗燃脂团课招生海报**
- **1v1 名师私教课、周度/月度课表发布、打卡陪跑营、早鸟特惠大促招生海报**
- AI 工具教程、部署上手封面
- 产品横评、榜单与多维对比封面
- 效率工作流、科普问答与好物种草推荐封面

## 包含内容

```text
vincent-xhs-cover/
  SKILL.md
  agents/
    openai.yaml
```

- `SKILL.md`：Skill 主体说明、智能推荐路由表、8 步交互式单选题流程（支持一键预设）和 **15 种封面与招生海报提示词模板**。
- `agents/openai.yaml`：OpenAI/Codex 侧的展示名、简介和默认调用提示。

## 安装方式

把 `vincent-xhs-cover` 目录复制到 Codex / Claude / Copilot skills 目录：

```bash
# Codex
cp -R vincent-xhs-cover ~/.codex/skills/

# 通用 Agent Skills 目录
cp -R vincent-xhs-cover ~/.agents/skills/
```

安装后可以通过下面的方式调用：

```text
$vincent-xhs-cover
```

或直接描述需求，例如：

```text
用 vincent-xhs-cover 帮我生成一张普拉提器械私教招生小红书海报提示词。
```

## 核心亮点与升级优化

1. **8 款干货爆款封面 + 7 款高转化课程招生海报**：风格 1–8 专注内容点击率，风格 9–15 专为课程/瑜伽/普拉提/训练营招生打造，内置完整转化信息架构（课程主标题 + 导师/教练真人主视觉 + 3 大课程收益/排期课表 + 底部早鸟/体验课预约 CTA）。
2. **“极速一键预设”与“精细定制”双轨体验**：
   - 第 1 问支持选 `0. 交给模型智能推荐`。
   - 第 3 问支持选 `0. ⚡ 一键采用当前风格全套最佳视觉预设`，选完人物、素材和标题即可极速出词，免去逐题选背景/字体/配色的繁琐。
3. **主页固定配色截图保持**：第 7 问支持上传过往封面/海报截图，自动提取标题主色、关键词强调色和描边逻辑，保持主页视觉统一。
4. **7 项出图前强制质量复核**：内置比例锁死（防止横向参考图带偏 3:4 竖版画幅）、五官防遮挡、手部与运动肢体解剖结构约束、黄色统一 `#FDFFA7` 色号铁律、零占位符残留检查。
5. **一鱼多吃横版扩展（4:3 & 16:9）**：默认先做 3:4 竖版小红书封面/招生海报；定稿后可一键重构成左右分栏的 4:3 和 16:9 横版海报提示词（适配公众号首图、社群招生横图、朋友圈、B 站）。

## 15 种风格一览

### 体系一：经典高点击大字抠图体系（风格 1–8，适合干货/测评/教程）
1. **爆款大字压顶风** — 顶部超大标题压住画面，人物居中，适合强钩子标题
2. **巨字拆分冲击风** — 2–4 个核心大词拆开放满画面，适合概念/身份/能力类主题
3. **小白科普问答风** — 黑灰科技海报或真实室内背景，问号和解释感，适合“什么是/怎么理解”
4. **教程清单风** — 绿色勾选清单 + 步骤感，适合安装、部署、上手教程
5. **产品测评榜单风** — 大数字、箭头、维度标签，适合横评、榜单、测评
6. **种草推荐风** — 人物点赞或推荐姿势，emoji 和温暖背景，适合资源/播客/工具推荐
7. **贴纸拼贴入门风** — 人物 + 小卡片 + 产品图标 + 贴纸，适合“入门/搭建/组合”
8. **黑底效率工作流风** — 深色背景 + Logo 墙 + 清单，适合工作法、效率流、工具组合

### 体系二：高转化课程 / 瑜伽 / 普拉提 / 训练营招生海报体系（风格 9–15）
9. **苹果极简杂志风·名师私教招生海报** — 高级银白/暖灰渐变、毛玻璃课程大纲悬浮卡、导师商业杂志肖像与底部私教预约胶囊，适合高客单价 1v1 私教、主理人大师课、精品教培招募
10. **备忘录手写便签风·课表大纲招生海报** — 备忘录方格纸肌理、拍立得导师贴画、`#FDFFA7` 荧光笔划重点课程名、手写勾选周课表与朱红笔名额提醒，适合周/月课表发布、零基础入门班、打卡陪跑营招生
11. **多巴胺高饱和插画风·活力团课招生海报** — 高饱和糖果撞色、双层波普教练贴画、3D 立体大字与 `#FDFFA7` 锯齿爆炸福利贴，适合燃脂暴汗团课、尊巴/有氧舞蹈、周末活力训练营招生
12. **醒目大字报纯享风·限时特训招生海报** — 街头海报级巨型痛点/特惠大字占满版面、黑黄 `#FDFFA7` / 红白黑强反差、导师破格穿插与底部早鸟倒计时横幅，适合周年庆大促、早鸟立减、痛点暴击特训营招生
13. **Bento 卡片网格风·全维课程体系招生海报** — Apple 发布会式 5 格圆角卡片矩阵，分格清晰展示“课程主标题 + 导师主卡 + 课时/班型数字卡 + 3 大训练模块 + 报名福利卡”，适合体系化训练营、教培考证、套餐卡招生
14. **自然疗愈呼吸感·瑜伽/冥想招生海报** — 晨光百叶窗原木绿植瑜伽馆、燕麦米白与鼠尾草绿自然光影、导师舒展体式、3 大疗愈卖点亚麻卡 + 底部 `#FDFFA7` 早鸟限额招募横幅，适合流瑜伽、阴瑜伽、冥想音疗、周末工作坊招生
15. **精准体态美学·普拉提私教招生海报** — 核心床（Reformer）现代明亮场馆、人体工学流线美学弧线、3 大部位改善指标卡（天鹅颈直角肩 / 核心收紧 / 骨盆正位）+ 底部限时私教体验预约栏，适合普拉提器械私教、产后修复、体态矫正招生

## 设计规范

- 固定 **3:4 竖版**小红书封面/招生海报比例（定稿后支持重构成 4:3 与 16:9 横版）。
- 全风格**真人出镜**（基于图 1 保持五官与人物一致性），人物通常占画面 34%–50%。
- 主标题必须超大、清晰、短促，确保移动端信息流一眼可读。
- 凡使用黄色系（标题填充、关键词、底板、色块、招生横幅、荧光马克笔、爆炸福利贴），统一指定为柔和浅黄色 `#FDFFA7`，避免刺眼柠檬黄或偏橙黄。
- 重要文字、人物脸部（眼睛和嘴巴）及核心模块内容绝不超出安全区，文字绝不遮挡五官。
