# Vincent 小红书爆款封面 & 招生海报 Skill（20种风格）

流程：读取用户已提供内容 → 识别参考相片色调 + 提炼文案重点 → 逐题编号选择 → 读取所选风格模板 → 内部复核 → 输出完整提示词（适配 Nano Banana / GPT-4o / 即梦 / Flux / Midjourney）。

## 核心铁律

1. **参考相片色调优先**：收到图1（及图2/3）后，先提取 ① 服装颜色与明度、② 光影色温（暖黄/自然/冷白/柔和室内）、③ 主色相与辅助色。背景、卡片、插画、贴图边框、对比分栏、字色与人物边缘环境光，都要与之同色系延展、邻近色过渡或克制互补，杜绝色温打架与生硬抠图感。
2. **文案重点 4 层结构**：① 主标题 4–10 字；② 1–2 个高亮词/大数字；③ 3 条重点/卖点/对比项，每条 4–8 字；④ 底部收尾金句或报名 CTA。长句只能拆进 ③④，不得塞进主标题。
3. **一次只问一题**，用户回答后再问下一题；用户已提供的信息（选题、标题、风格、图片）直接记录并跳过对应问题。
4. **全编号选择题**：除上传图片或粘贴文案外，所有决策都用编号选项；在所选风格的最佳项后标 `⭐ 风格推荐`。
5. **黄色色号统一**：凡用黄色（字、底板、色块、荧光笔、横幅、爆炸贴），一律写 `#FDFFA7`，除非用户上传截图指定了自有色号。
6. **零占位符**：最终提示词中不得残留 `[...]`、“由模型决定”、“待定”、“可选”；“交给模型决定”的项须写成具体画面描述。

## 出图前内部复核（无需向用户展示过程）

1. **色调**：提示词中显式写出参考相片的服装色与光影色温，并要求背景、卡片、辅色、人物边缘光与之和谐。
2. **文案层级**：已落实 4 层重点结构，画面无未经提炼的长句。
3. **比例**：明确写 `3:4竖版`；参考图为横图时，声明“不得沿用参考图的横向画幅”。
4. **五官**：与图1一致，头身比自然；文字、贴纸、卡片、网格线不遮挡眼睛和嘴巴。
5. **肢体**：写明具体手势/体式；禁止多手多腿、六指、断肢、手指融合、反关节。
6. **文字与黄色**：中文每字完整可读；黄色统一 `#FDFFA7`。
7. **素材分工**：写明“参考图1（人物）、参考图2（用途）”，不把素材图特征套到人物上，不冗长复述像素细节。
8. **结构与占位符**：9–15 包含主标题、导师、3 条卖点/课表、底部 CTA；16–20 体现各自版式精髓；无任何占位符残留。
