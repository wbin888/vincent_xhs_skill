# 美学风格库（A1–A173）· 可叠加在 21 种版式之上

> 风格清单与分类学习自公众号「爱折腾的摄影大叔」雷鹏《我把 173 种美学风格写成了可直接复制的提示词》（2026-09-29，https://mp.weixin.qq.com/s/lcn5_Jd_5YpU-oEN9c6KZA）。本文件为针对小红书封面/招生海报场景的重新提炼与改写，未收录原文图片。

**版式 vs 美学**：风格 1–21 决定**版式骨架**（标题位置、卡片、人物落位、重点结构）；A1–A173 决定**画面气质**（色彩、构图倾向、质感、光线）。两者正交，一张图 = 1 个版式 + 0–2 个美学。

## 叠加规则

1. **最多 2 个**：推荐「1 个造型/媒介风格（A1–A138、A152–A173）+ 1 个色彩/光影风格（A109–A119、A139–A151）」，最稳；两个同类造型风格（如水墨 + 赛博朋克）禁止叠加。
2. **参考相片色调仍优先**：美学色板与图1服装色/色温冲突时，保留美学的**构图、质感、光线**，色彩改为“向图1主色靠拢的同名色调变体”（如莫兰迪 → 取图1服装色的灰化版）。优先推荐色板本就与图1接近的美学。
3. **版式不被吞掉**：美学只作用于背景、插画/贴图、卡片材质、人物光影与整体调色；所选版式的标题位置、3 条重点、CTA、卡片数量保持不变。
4. **人物不被风格化过度**：照片类版式（1–15、18–20）中人物保持真实摄影质感与图1五官一致，美学只体现在环境、光线和调色；只有用户明确要求“把人物也画成 X 风格”时才转绘人物，且仍需五官神似。
5. **文字永远清晰**：美学质感（宣纸、颗粒、故障、网点、霓虹光晕）不得覆盖标题与重点文字；文字区可用纯色衬底隔离。
6. **黄色规则不变**：标题字、底板、荧光笔、横幅等**设计元素**的黄色仍统一 `#FDFFA7`；美学自带的颜料黄（藤黄、铬黄等）只用于场景/插画内部。
7. **风格 21（单色印刷版）** 只可叠加 A79/A85/A86/A87/A147/A148/A158/A163，且色彩仍按风格21墨色表，不超过 2 种油墨。
8. **† 标记**（动画工作室 IP / 在世艺术家相关）：最终提示词中**不写名称**，改写为表中的特征描述（如“吉卜力” → “手绘水粉厚涂、通透蓝绿天空、治愈系田园动画质感”），避免商用海报的 IP 风险，同时各生图模型理解更稳定。
9. 支持权重语法的工具（SD/Flux WebUI、Midjourney `::`）可写 `(风格词:0.6)` 弱化、`(风格词:1.3)` 强化；Nano Banana / GPT-4o / 即梦用自然语言“轻微带一点…/以…为主导”表达强弱。

## 写进提示词的方式

在所选版式模板的【人物】段之后、【禁忌/材质】段之前插入一段（不得残留方括号）：

```text
【美学风格】：整体画面融入[美学名称]气质——色彩[色彩，已按参考图1色调校准]，[构图倾向，作用于背景与留白，不改变版式骨架]，[质感]，[光线]。该美学只作用于背景、插画/卡片材质与环境光，人物保持图1真实五官与[照片/插画]质感，所有文字区域保持干净可读。
```

反向词追加：`低清、模糊、畸形手、多余手指、过曝、塑料感、文字乱码`；写实摄影类美学再加 `插画感`，插画/绘画类美学再加 `照片感`（人物仍为真人照片的版式除外）。
