# 风格 22–194：美学风格库（173 种）· 通用美学封面版式

> 风格清单与分类学习自公众号「爱折腾的摄影大叔」雷鹏《我把 173 种美学风格写成了可直接复制的提示词》（2026-09-29，https://mp.weixin.qq.com/s/lcn5_Jd_5YpU-oEN9c6KZA）。本文件为针对小红书封面/招生海报场景的重新提炼与改写，未收录原文图片。

风格 22–194 与 1–21 同级，一次只选一个编号。1–21 各有专属版式；22–194 统一套用下方的**通用美学封面版式**，画面气质（色彩、构图倾向、质感、光线）由所选编号那一行决定。

## 本组规则（覆盖或补充全局铁律）

1. **只读所选那一行**：从下方分类表中取该编号的「色彩 / 构图 / 质感 · 光线」，套进模板；不要混入其他编号的特征。
2. **参考相片色调融合**：保留美学的核心色板、质感与光线，把图1服装色作为色板中的邻近色或点缀色融入；若服装色与色板强烈冲突，场景色向服装色相轻微偏移，但质感与光线不变。
3. **人物处理（按类别默认）**：
   - 摄影与光影（130–140）、色彩与调性（160–172）、176 电影写真：人物保持真实摄影质感。
   - 其余绘画/插画/设计类：人物以该美学重新绘制（如水墨、浮世绘、赛璐珞、黏土），五官、发型、脸型与图1高度神似；用户要求“人物保持真人照片”时改为真人 + 美学环境。
4. **文字永远清晰**：美学质感（宣纸、颗粒、故障、网点、霓虹光晕）不得覆盖标题与重点文字；必要时用与美学协调的纯色衬底、留白区或题签承载文字。
5. **黄色规则不变**：标题字、底板、荧光笔、横幅等设计元素的黄色统一 `#FDFFA7`；美学自带的颜料黄（藤黄、铬黄等）只用于画面内部。
6. **† 标记**（动画工作室 IP / 在世艺术家相关）：最终提示词中**不写名称**，改写为表中的特征描述（如“吉卜力式” → “手绘水粉厚涂、通透蓝绿天空、治愈系田园动画质感”），避免商用海报的 IP 风险。
7. 支持权重语法的工具（SD/Flux WebUI、Midjourney `::`）可写 `(风格词:1.3)` 强化；Nano Banana / GPT-4o / 即梦用自然语言“以…为主导”表达。

## 通用美学封面版式

- **结构**：顶部约 30% 为标题区（主标题 + 高亮词）；中部人物占画面 45%–60%，偏中或偏一侧，按该美学的构图倾向安排（对称、留白、对角线、满构图等）；3 条重点以与美学协调的小型文字载体分布在人物旁侧；底部 10%–12% 为 CTA 信息条。
- **文字载体随美学变化**：

| 类别 | 主标题 | 3 条重点载体 | CTA |
|---|---|---|---|
| 东方古典（22–58） | 书法/粗宋竖排或横排题字 | 竖排题签、朱砂小印章 | 素笺条 + 一枚朱印 |
| 日本与东亚（59–70） | 和风粗明朝体/手写体 | 短册纸签、圆形家纹标 | 和纸细条 |
| 世界区域（71–82） | 与地域纹样匹配的装饰粗体 | 纹样边框小牌 | 织物/纸质横条 |
| 西方艺术（83–110） | 杂志衬线或该流派海报字 | 画框标签、展签 | 美术馆展签式小字 |
| 数字科幻设计（111–129） | 几何粗黑 / 霓虹 / 像素 / 镀铬字 | UI 标签、像素框、全息卡 | 界面按钮条（不做真实按钮质感） |
| 摄影与光影（130–140） | 杂志刊头粗黑 + 细衬线 | 胶片边框标注、相纸手写 | 底部细线信息带 |
| 插画动画绘本（141–159） | 圆润手绘粗体 / 漫画标题字 | 对话框、贴纸、手绘小卡 | 手绘横幅 |
| 色彩与调性（160–172） | 极简粗黑，取色板最深色 | 同色系胶囊标签 | 色块细条 |
| 亚文化暗黑（173–175） | 哥特黑体 / 尖角衬线 | 蕾丝/金属铭牌 | 暗色细条 |
| 补充风格（176–194） | 按该行媒介选择（版画/漫画/印刷体） | 与媒介一致的小标签 | 细条信息带 |
