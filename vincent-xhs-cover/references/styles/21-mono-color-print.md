# 风格 21：单色印刷版（孔版网点·编辑印刷风）

> 改编自 [yanliudesign/mono-color-skill](https://github.com/yanliudesign/mono-color-skill)（MIT License，© 2026 Yan Liu），许可声明见 `THIRD_PARTY_NOTICES.md`。仅改编文字规则，未使用其示例图片。

把真人照片转成**一色或两色油墨的网点印刷品**：中性纸底 + 不超过 2 种油墨 + 网点人像 + 大胆的标题与人像碰撞 + 克制留白。像独立杂志封面、文化活动海报或 zine，而不是数码调色滤镜。适合有调性的个人品牌、读书/观点/文化类干货、展览/活动、高审美工作室与小众课程海报。

## 本风格的例外规则（覆盖全局铁律）

- **油墨上限**：整张画面最多 2 种印刷油墨（纸底不算），**不使用全局 `#FDFFA7` 黄色**，除非用户主动选它作为两种墨之一。
- **色调和谐**：不是让背景去配照片，而是把参考相片**转印成油墨**。从下方墨色表中选与参考照服装/主色相最接近的墨，作为主版。
- **文案语气**：短、具体、像观察或宣言，不用“限时/抢/爆”等促销腔；CTA 写成一行克制的事实信息（如 `每周六 10:00 · 6 人小班 · 私信报名`）。
- **语言**：保留用户中文原文；可加 1 行英文小字作为版式纹理，不编造机构、网址或赞助方。
- **人物**：标题可以压过人物的身体、肩线或画面边缘，但**不得遮挡眼睛和嘴巴**。

## 视觉特征

- **纸底（3 选 1）**：中性白 `#FAFAF7`（默认，文化/活动/人像）｜冷灰 `#E9E9E5`（科技/建筑/理性）｜浅米 `#F5F1E8`（食物/旅行/私密/怀旧）。默认是当代编辑感，不做泛黄、做旧、复古道具，除非用户要求。
- **印刷模式**：
  1. 纯一色：只用一种墨，靠网点疏密表现明暗（用户说“单色/一个颜色”时）
  2. 彩色墨 + 黑：彩色版印人像/主图，黑版印正文和标注（安静、观察、长文）
  3. 互补双色（默认）：主墨占 70%–85%，辅墨占 15%–30%，且只用于 1 个指定角色（高亮词、日期、圈注）
  4. 叠印双色：两版在局部重叠，重叠处自然变深（不算第三色）
- **墨色表**（按参考照主色就近选取）：

| 参考照主色 / 主题 | 推荐墨色 |
|---|---|
| 蓝色系、科技、知识、城市（默认） | 钴蓝 `#2148B8` + 赤陶橙 `#C65F38` |
| 绿色系、植物、书店、自然 | 植物绿 `#008A4B` + 牛血红 `#8F3434` |
| 浅绿、清新、日记、长文 | 薄荷绿 `#5EB783` + 暖炭黑 `#302D2E` |
| 黑白灰、建筑、展览、理性 | 炭黑 `#30343A` + 信号红 `#C83232` |
| 橙红、运动、街头、年轻 | 群青 `#263E99` + 安全橙 `#E55D2B` |
| 高对比文化活动、人像大片 | 电光蓝 `#173AE3` + 碳黑 `#242321` |
| 产品重复、展览、俏皮信息 | 青 `#159DDA` + 砖红 `#B64032` |
| 市集、节日、大字通知 | 橘 `#E46C2D` + 石板蓝 `#4773A5` |
| 指南、通知、信息密集 | 粉蓝 `#9EB8D3` + 信号红 `#C83232` |
| 紫/夜晚/电影/文学（单色） | 茄紫 `#63365F` |

- **构图**：留白 25%–55%；外边距 5%–9%；对齐一条隐形左边线或 2–3 栏网格；**不居中对称、不做卡片网格**。
- **一个焦点事件**：超大标题 / 极端人像裁切 / 巨大局部细节 / 叠印碰撞 / 反常比例，**只选 1 个**；另留 1 块安静的释放区。
- **四个动作**：① 人物（或一个物件）占 45%–80%，果断出血裁切；② 标题与人像碰撞（交叉、压住、包夹或紧贴）；③ 纸白切进图像（高光溢出、网点淡出、镂空）；④ 只有 1 种手作痕迹（一个手绘圈、一条手画线、套准标记或一行旋转小标签）。
- **人像处理**：网点/孔版印刷质感，近看见点、缩略图仍可辨认；高光露出纸白，暗部油墨堆积；当代感用清晰分色或中等网点，粗网点只在需要质感时用；可有轻微套版错位 1–2 mm、墨色不均、纸纤维（当代风 0–2 种，复古风 2–3 种）。
- **字体（选 1 套）**：
  - 文学衬线：小写感、自然断行，适合读书、生活、私密观察
  - 宽体怪诞无衬线：字母可紧贴互锁，适合音乐、时尚、运动、年轻文化
  - 压缩粗黑：堆叠大标题、日期从属，适合活动、招生、通知
  - 程序化信息体：等宽数字 + 细线分区，适合课表、日程、多场次
  - 旋转大标题：标题旋转 90° 或竖排，适合大胆封面
  - 文字即主体：超大字被裁出画面，适合金句、宣言
  - 最大字是最小字的 5–12 倍；不用渐变字、描边字、投影、3D 字。
- **版式家族**（按内容选第一个匹配）：活动/课表/通知 → 横线信息海报｜植物/收藏 → 档案图版｜同一物件重复 → 物件阵列｜两层图像交叉 → 叠印拼贴｜一张人像照 → 图像满版｜1–3 个物件对比 → 标本注解｜文字本身是主角 → 文字宣言｜随笔/日记 → 编辑日志｜其他 → 杂志封面
