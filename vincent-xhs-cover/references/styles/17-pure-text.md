# 风格 17：纯文本版（高审美纯文字排版·重点金句直出风）

不放大幅人物抠图（可100%纯文字排版，或仅在角落/底部嵌入一枚极简圆形作者小头像徽章），完全依靠殿堂级杂志/海报字体设计、极致字号层级反差、柔和浅黄色 `#FDFFA7` 重点高亮块与严谨网格留白，将提炼出的文案重点变成一秒锁死视线的“文字视觉锤”。同时严格先提取参考相片的色调作为整张纯文本海报的配色基准，保持主页与品牌视觉高度和谐。

## 视觉特征
- 色调基准：先从参考相片（图1）中提取主色调、辅助色与冷暖明暗气质，转化为高级纯色或微肌理艺术纸背景底色、卡片底色与标题配色，搭配柔和浅黄色 `#FDFFA7` 重点高亮色块，色彩克制高级且和谐统一
- 版式结构（纯文字4层重点架构）：
  1. **顶部栏目眉题/标签**：精致胶囊标签 + 细分割线，点明主题分类或课程期数
  2. **视觉中心巨型主标题**：占据画面 45%–55% 核心视觉区，字号极大、字重极粗，核心关键词用 `#FDFFA7` 底板或撞色高亮圈出
  3. **中下部结构化 3 大核心重点（01 / 02 / 03）**：将繁杂正文浓缩为3条对仗工整的短句重点，配清晰序号与卡片分栏
  4. **底部收尾金句 / 报名行动栏（可带极简作者小头像徽章）**
