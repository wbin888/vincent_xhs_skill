# 活动策划手册（模式 C 使用）

## 1. 先定目标，再定机制

| 目标 | 核心指标 | 推荐机制 |
|---|---|---|
| 拉新获客 | 到店体验人数、首单转化 | 低价体验课（9.9/19.9/0 元）、新人体验包、老带新双方得、团购引流 |
| 老会员续费 | 续卡率、预收款 | 续卡加赠天数/课时、老会员专享价、积分兑换、阶梯续费（越早越优惠） |
| 预收现金（开业/大促） | 预售金额 | 早鸟价 + 限量名额、定金膨胀、阶梯涨价（前 50 名/前 100 名）、年卡大促 |
| 品牌曝光/节日氛围 | 曝光、到店、UGC | 公开课/快闪课、主题派对、打卡赢礼、节日限定周边 |
| 淡季促活 | 上课率、沉睡唤醒 | 挑战赛（21 天打卡）、签到返现、课程盲盒、主题周 |
| 新课程/新老师 | 报名人数 | 首发体验价、老师见面会、小班招募、工作坊 |

## 2. 机制库（按馆型）

### 瑜伽馆 / 冥想
- 店庆感恩月：公开课免费 + 老会员续卡加赠 30 天 + 带朋友各得一节私教
- 21 天晨练打卡：全勤返课时/送定制瑜伽垫
- 世界瑜伽日（6.21）：户外/屋顶公开课、108 拜日式挑战
- 母亲节：母女同行一人免单、亲子瑜伽
- 工作坊：早鸟价（截止日前 X 天）+ 老学员价

### 健身房 / 团操
- 双11/618：年卡限时折扣 + 私教课包加赠 + 定金膨胀（100 抵 300）
- 开业预售：阶梯价（前 100 名 ¥999 → 前 300 名 ¥1299 → 正式价）
- 减脂营/体测挑战：报名费 + 达标退款/返课
- 新年 Flag：签到满 X 次返现、组队打卡
- 夏日燃脂季：团课畅练月卡

### 普拉提馆
- 会员日（每月固定日）：私教课包会员价 + 体态评估免费
- 器械体验：首节器械私教 ¥99/¥199
- 产后修复专场、母亲节双人课
- 老带新：推荐成功双方各得 1 节

### 运动康复馆
- 免费体态/足型筛查日（公益性质获客）
- 开学季：青少年脊柱侧弯筛查、体态评估
- 跑者季：马拉松赛前/赛后护膝讲座 + 评估
- 健康讲座：久坐办公族肩颈、产后腹直肌
- **注意**：不得承诺疗效，强调“评估、训练、改善建议”，需注明非医疗诊断。

### 心身灵工作室
- 满月/新月冥想、节气主题冥想（立春、夏至、冬至）
- 年终觉察工作坊 / 新年愿景板
- 读书会、正念 8 周课程招募（早鸟价）
- 双人/亲子共修

### 音乐疗愈 / 颂钵
- 满月颂钵音浴之夜（限 16 人小班）
- 助眠专场（周五夜晚）、午休疗愈 30 分钟（写字楼周边）
- 双人同行价、企业团建定制
- 节日限定：中秋“月光音浴”、冬至“长夜好眠”

## 3. 价格结构设计原则

- **锚点**：每张海报最多 1 个主价格 + 1–2 个辅助价格。主价格放在 `offers[0]`，配 `tag`（限量/早鸟/会员专享）。
- **原价真实**：`original` 必须是近期真实售价；不确定时不写原价，改写“会员专享”“限时”。
- **低门槛钩子**：拉新活动的首个价格建议 ≤ ¥99（体验课）。
- **稀缺性**：名额、截止时间要真实可执行（“限前 30 名”“11.30 截止”）。
- **赠品优于降价**：高端馆型（普拉提/私教/疗愈）优先“加赠课时/天数/周边”，避免破坏价格体系。

## 4. 活动节奏（建议告诉用户）

| 阶段 | 时间 | 物料 |
|---|---|---|
| 预热 | 活动前 7–10 天 | 预告海报（9:16 朋友圈/社群）、悬念文案 |
| 爆发 | 活动期 | 主海报（3:4 小红书 + 1:1 社群 + 16:9 门店屏） |
| 返场/收尾 | 最后 1–2 天 | “最后 X 名/倒计时”海报（同风格改 hero） |
| 复盘 | 活动后 | 感谢海报 / 活动花絮 |

倒计时海报做法：复制 spec，改 `eyebrow`、`hero`（如 `{"value":"2","unit":"天","label":"活动倒计时"}`）和 `output_name`。

## 5. 方案输出模板（模式 C 一次给 3 套）

```
### 方案 1｜稳妥型：<主题名>
- 目标：拉新 / 续费 / 曝光
- 时间：<日期>（预热 <日期>）
- 核心机制：<1 句话>
- 价格结构：主推 <名称 ¥价格>（原价 ¥X）＋ 辅助 <名称 ¥价格>
- 附加权益：<2–3 条>
- 海报主标题：<≤7 字/行，2 行>
- 推荐风格：<style>（理由）
- 执行要点/风险：<1–2 条>

### 方案 2｜爆发型：……（强促销、强稀缺）
### 方案 3｜情感型：……（品牌温度、社群关系、低折扣高价值）
```

所有价格若为你的建议值，在方案末尾注明：“以上价格为建议，请按门店实际确认后再出图。”最后问一句：“选择哪个方案？可回复编号，或告诉我想修改的地方。”
