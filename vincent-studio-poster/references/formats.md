# 四种规格

| 比例 | 输出像素 | 主要用途 | 版式思路 |
|---|---|---|---|
| **3:4** | 1242 × 1656 | 小红书笔记封面、朋友圈单图、大众点评、门店 A 字架/易拉宝预览 | 信息最完整的“主海报” |
| **9:16** | 1080 × 1920 | 抖音/视频号/小红书竖版、朋友圈长图、微信状态、电梯屏、手机壁纸 | 单栏纵向，图片居中，信息自上而下 |
| **1:1** | 1080 × 1080 | 朋友圈九宫格、微信群/社群、美团/点评商品图、大众点评团购主图 | 左右分栏，精简信息 |
| **16:9** | 1920 × 1080 | 公众号首图（裁切）、B 站封面、门店电视/投影、课程大屏、PPT | 横向三栏，照片占一侧 |

需要更高清（印刷、门店大屏）：加 `--scale 2` 得到 2 倍像素。印刷海报（如 60×80cm）建议 `--scale 3` 并让印刷厂确认。

## 各规格信息密度建议

| 元素 | 3:4 | 9:16 | 1:1 | 16:9 |
|---|---|---|---|---|
| 主标题 | ✓ | ✓ | ✓ | ✓ |
| 副标题 | ✓ | ✓ | 可删 | ✓ |
| hero 大数字 | ✓ | ✓ | ✓ | ✓ |
| 卖点 | 3–4 | 3 | 2–3 | 3 |
| 价格卡 | 1–3 | 1–2 | 1–2 | 1–3 |
| 地址/电话 | ✓ | ✓ | 可只留地址 | ✓ |
| 规则小字 | ✓ | ✓ | 自动隐藏（部分风格） | ✓ |

用 `by_ratio` 对 1:1 做减法最常见。

## 平台安全区

- **小红书 3:4**：底部约 8% 会被标题/点赞栏遮挡（在信息流中），关键价格不要贴底边。
- **抖音/视频号 9:16**：顶部 12%（状态栏/标题）与底部 20%（文案、按钮）、右侧 15%（点赞栏）可能被遮挡；作为视频封面时，主标题应在中上部。本 skill 的 9:16 版式已将主标题放在上 1/3，CTA 在底部，若用于视频封面可用 `by_ratio` 去掉底部小字。
- **公众号首图**：显示比例 2.35:1，16:9 会被裁掉上下各约 12%，主标题需在垂直中间区域。
- **朋友圈 1:1**：缩略图极小，标题字数越少越好（≤ 6 字最佳）。
