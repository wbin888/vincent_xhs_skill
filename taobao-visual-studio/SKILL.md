# 淘宝视觉工作室（Taobao Visual Studio）

把「商品图 + 卖点」变成一套**可上架**的淘宝主图与详情页。融合 5 个开源电商做图 Skill 的长处（见 `references/source-analysis.md`）。

```
0 建任务目录 → 1 读图&补全信息 → 2 消费者卖点地图 + 驱动力诊断 → 3 产品身份锁定
→ 4 统一策划表（主图5 + 详情N）【审批闸门】 → 5 风格锁 + 逐张 Prompt → 6 出图
→ 7 自检（平台规范 / 违禁词 / 视觉质量）→ 8 交付
```

## 工作模式

| 模式 | 触发 | 输出 |
|---|---|---|
| **策划模式**（默认） | 未明确要求出图 | 策划表 + 风格锁 + 全部 Prompt |
| **出图模式** | 「生成/出图/直接做」 | 策划表审批后逐张生成并自检 |
| **单图模式** | 只要一张（如白底图） | 跳过统一策划，仍执行铁律与自检 |

## Step 0：建任务目录（出图模式必做）

在当前工作目录建 `taobao-visual/<YYYYMMDD-HHMM>-<商品简称>/`，含 `主图/ 详情页/ prompts/ 记录/`。所有产物只写入本目录，**绝不写入已有旧任务目录**。

## Step 1：读图 & 信息补全

1. 先用自身视觉能力看用户上传的商品图（1-N 张），识别：品类、外观、颜色、材质、结构、包装、可见文字/logo。
2. 只上传了图、没给卖点时，**只问一次**：「有卖点、参数、品牌色、目标人群、价格带或资料文档要补充吗？没有我就根据图片和品类推断。」
3. 按优先级补全，并给每条信息打来源标签：
   `用户提供` > `图片/附件` > `联网查证`（官网/公开商品页）> `推断` > `默认`
4. 必须确认的项：**目标平台**（默认淘宝）、**主图比例**（1:1 或 3:4）、**是否要详情页**。
5. 任何 `推断/默认` 内容，在最终交付中列出「假设清单」。

最小输入字段：商品名、品类、核心卖点 3-5 条、目标人群、使用场景、规格参数、价格带、品牌色、已有证据（检测报告/专利/证书/真实评价）、促销信息。

## Step 2：消费者卖点地图 + 转化驱动力

先写**消费者卖点地图**（`references/sequences.md` §1）：品类焦虑 → 想要的结果 → 使用时刻 → 购买顾虑 → 什么证据能让人信。

再判定 1 个主驱动力（可加 1 个次级）：

- **颜值驱动**：外观/质感/送礼 → 主图重材质光影与氛围
- **痛点驱动**：解决具体麻烦 → 问题快照 → 解决机制 → 效果证明 → 信任 → 促销
- **情感驱动**：身份/关怀/向往 → 情绪场景 → 产品是实现方式 → 社交信号

输出一张**购买理由卡**：目标买家 / 购买触发 / 认知转变（旧认知→新认知）/ 唯一主卖点 / 证据素材 / 促销杠杆。

## Step 3：产品身份锁定

- 有清晰产品图：后续所有出图都**以原图作参考图**（edit/图生图），prompt 写 preserve 清单：`保留：外形、颜色、logo 位置、材质纹理、包装文字`。
- 只有 1 张图或角度不全，且需要多角度：先生成一张**临时角度锁定图**（正面/45°/侧面/背面/关键细节，浅色棚拍底，无营销元素），用户确认产品没跑偏后，作为后续参考图。跑偏就先重生角度图。
- 服装/鞋类需要模特：先生成 1 张模特定妆图，确认后同批次锁定同一模特。**不复刻可识别真人**。

## Step 4：统一策划表【审批闸门】

主图和详情页**一起策划、一次审批**。按 `references/sequences.md` 选序列，输出一张表：

| # | 位置 | 本张任务（推动什么） | 画面独立陈述 | 主体/产品露出 | 镜头角度·景别 | 背景色 | 文案（主标题/副标题/标签） |
|---|---|---|---|---|---|---|---|

硬规则：
- **画面独立测试**：每行先写一句「画面是____，遮住全部文字仍能看出____」。写不出来就重新设计画面。
- **产品露出由信息决定**：成分/质地/场景/机制类屏可以不出现整包装。
- **多样性下限**：5 张主图 ≥4 种主视觉、≥3 种角度且含 1 张特写；详情页 ≥70% 屏主视觉不同、≥4 种角度、≥2 张特写/微距；不得连续 3 张同角度；全景 ≤40%。
- **背景节奏**：交替 2-3 种背景色，避免视觉疲劳。
- **文案消费者口吻**：写买家得到什么、不再担心什么；禁止说明书腔（"采用XX技术""本品具有"）。
- 文案先过 `scripts/lint_copy.py`（《广告法》极限词等）。

等用户批准或修改后再写 Prompt。用户明确说「跳过审核/直接出」才可跳过。

## Step 5：风格锁 + 逐张 Prompt

1. 建 **Campaign Style Lock**（10 字段，见 `references/prompt-craft.md` §2）；可从 6 套风格预设中推荐 1 套让用户选。
2. 每张图一个独立 Prompt，**第一段原样粘贴同一段 Style Lock**；单张只允许改：画面目的、主体动作、局部构图、短文案。
3. Prompt 用 5 段式：**场景 / 主体 / 关键细节（含文案）/ 用途 / 约束**（`references/prompt-craft.md` §1）。
4. 必须遵守**生图铁律**（§3）：hex 颜色、产品占比数字化、显式留白、具体否定清单、淘宝主图避让区、中文文案用「」包裹且每屏 ≤50 字。
5. 详情页 Prompt 以「电商详情页信息屏 / E-commerce infographic screen」开头，是带标题、卖点、对比或步骤的信息屏，不是换角度的产品照。
6. 生活/买家秀类加去 AI 感写法（§5）。
7. Prompt 存到 `prompts/主图-01.txt`、`prompts/详情-01.txt` …

## Step 6：出图

按通道优先级：
1. **Agent 内置生图工具**（如 imagegen / image generation）→ 直接调用，传参考图。
2. **OpenAI 兼容端点**：`python3 scripts/generate_image.py --prompt-file prompts/主图-01.txt --size 1024x1024 --image <产品图> --out <任务目录>/主图/01-xxx.png`（需 `IMAGE_API_KEY`，可选 `IMAGE_API_BASE`、`IMAGE_MODEL`）。
3. 都不可用 → 只交付 Prompt 包，并说明配置方式。**不阻塞、不索要、不回显 API key。**

批量出图前报告张数与预计调用次数，确认后执行。主图生成 1:1（或 3:4），详情页生成 2:3 或 3:4 竖版；生成后再按平台尺寸导出（Step 7）。

## Step 7：自检（一轮只改一个最严重问题）

```bash
python3 scripts/check_image.py <任务目录>/主图/*.png --role main --platform taobao
python3 scripts/check_image.py <任务目录>/主图/05-*.png --role white --platform taobao
python3 scripts/check_image.py <任务目录>/详情页/*.png --role detail --platform taobao
python3 scripts/check_image.py <图> --role main --fix   # 自动导出为合规尺寸副本
```

再用视觉自检（`references/prompt-craft.md` §6）：产品是否跑偏、中文是否错字（放大逐字核对）、AI 痕迹（塑料肤质、多指、乱码、背景超现实）、风格是否漂移、是否通过画面独立测试。有问题 → 只改最严重的一处 → 重生该张（复用原 Style Lock）。

## Step 8：交付

1. 文件路径清单（主图 01-05、详情页 01-N）
2. 自检报告（`记录/验证报告.md`）：尺寸/白底/违禁词结果 + 重生记录
3. 假设清单（推断/默认内容）
4. 上架提醒：白底图放第 5 张（或按类目要求）；AI 生成的人物图按平台要求做 AIGC 标识；不剥离 C2PA/水印凭证

## 红线（任何模式都适用）

- 不编造：价格、销量、评分、认证、检测数据、专利、"国家级"背书、真实评价、医疗/功效承诺。没有证据就用占位（如「【检测报告占位】」）或换成可观察的表达。
- 不用《广告法》极限词与绝对化用语；特殊类目（化妆品/食品/保健/母婴/医疗器械）遵守 `references/compliance.md`。
- 不复刻可识别真人、不仿冒他人品牌/logo、不洗掉 AI 来源标记、不把 AI 图冒充实拍。
- 产品准确性优先于参考图风格；参考图只借「视觉语言」（光线、字体气质、密度节奏），其具体场景元素最多出现在 30% 的图里。
