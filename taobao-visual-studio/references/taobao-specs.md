# 平台图片规范速查

> 规范以各平台卖家后台最新规则为准，类目可能有额外要求。下表为常用/推荐值，`scripts/check_image.py` 内的阈值与本表保持同步。

## 淘宝 / 天猫

### 主图（5 张，可选主图视频）
| 项 | 推荐 |
|---|---|
| 比例 | 1:1（通用）；3:4 竖版（服饰、鞋包等类目常用） |
| 尺寸 | 1:1 → 800×800 起（≥700×700 才支持放大镜），推荐 800-1200；3:4 → 750×1000 起 |
| 格式/大小 | JPG / PNG，单张 ≤3MB |
| 第 1 张 | 点击率担当：一眼看懂产品 + 1 个主卖点，文字少而大 |
| 第 5 张（白底图） | 纯白 #FFFFFF 背景、无文字/logo/水印/边框/拼接、商品完整居中正面，用于手淘推荐等渠道 |
| 避让 | 不在四角放关键内容（平台会叠加角标/价格/活动标），推荐左上角与底部 15% 区域不放核心文字 |

### 白底图详细要求
- 背景纯白 RGB(255,255,255)，不得有阴影底板、渐变、场景道具
- 商品主体完整、不裁切、居中，主体约占画面 60%-80%，四周留白
- 无任何文字、logo 贴片、水印、牛皮癣；不得多件拼图（套装类目除外）
- 抠图边缘干净，无白边/锯齿/残留背景

### 详情页
| 项 | 推荐 |
|---|---|
| 宽度 | 手机端 750px（主流）；天猫 PC 详情 790px |
| 单屏高度 | 建议 1000-1500px/屏，单张切片高度不宜过长（建议 ≤ 2000px） |
| 格式 | JPG / PNG；单张建议 ≤ 1MB-2MB 以保证加载 |
| 屏数 | 8-12 屏常见；首 3 屏决定是否继续下滑 |
| 文字 | 手机端最小字号 ≥ 24px（750 宽画布），标题 40-60px |

生图时详情页按 2:3（如 1024×1536）或 3:4 生成，之后由 `check_image.py --fix` 等比缩放到 750 宽。

### SKU 图
- 1:1，800×800，按颜色/规格区分，同一套背景与角度

## 京东
- 主图 1:1，800×800 起，第一张通常要求白底或浅色底（视类目）
- 详情页宽 750（移动）/ 990（PC）

## 拼多多
- 轮播图 1:1，≥ 750×750（推荐 800×800），≤ 1MB-3MB
- 白底图 800×800 纯白
- 详情图宽 750，单张高 ≤ 1500 建议

## 抖音电商
- 主图 1:1 ≥ 600×600（推荐 800×800）；服饰类 3:4
- 白底图同淘宝要求
- 详情页宽 750 起

## 生图尺寸映射
| 交付 | 生成尺寸（模型常见） | 导出 |
|---|---|---|
| 主图 1:1 | 1024×1024 | 800×800 或 1200×1200 |
| 主图 3:4 | 1024×1365 / 768×1024 | 750×1000 |
| 白底图 | 1024×1024 | 800×800 |
| 详情页屏 | 1024×1536（2:3）或 1024×1365（3:4） | 750×1125 / 750×1000 |
