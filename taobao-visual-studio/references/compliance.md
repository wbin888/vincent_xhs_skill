# 合规速查（中国电商）

> 非法律意见。依据《广告法》第九条、第二十八条等常见要求和平台规则整理；上架前以平台后台检测与类目规则为准。`scripts/lint_copy.py` 内置词表与本文件同步。

## 1. 绝对化/极限用语（禁止）
最、最佳、最好、最优、最强、最高、最低、最大、最小、最新、最先进、第一、唯一、首个、首选、顶级、极致、极品、
国家级、世界级、全网第一、销量第一、NO.1、TOP1、100%、万能、永久、绝对、史无前例、遥遥领先、王牌、
领导品牌、填补国内空白、独家（无证明时）、全球首发（无证明时）

替换思路：「最好用」→「用了就回不去」；「第一」→ 写具体可证的事实（如「XX 检测机构实测 XX」——需真实报告）。

## 2. 虚假/无依据背书（无证据禁止）
国家认证、专家推荐、医生推荐、明星同款（未授权）、驰名商标（未认定）、质量免检、XX 万人好评、销量 XX 万、
专利（无专利号）、权威检测（无报告）。

## 3. 时限/促销欺诈
「仅限今天」「最后一天」「秒杀价」需与真实活动一致；不得虚构原价划线价。

## 4. 特殊类目
| 类目 | 禁止 |
|---|---|
| 普通化妆品 | 医疗术语：治疗、消炎、抗菌、祛痘、祛斑、生发、修复受损、药妆、换肤；特殊功效需特殊化妆品注册 |
| 食品/普通食品 | 预防、治疗、降血压、降血糖、排毒、抗癌、增强免疫力、减肥 |
| 保健食品 | 只能宣传注册批准的保健功能，须标「保健食品不是药物，不能代替药物治疗疾病」 |
| 母婴 | 「最安全」「无任何刺激」「100% 无害」等绝对化 |
| 医疗器械 | 需注册证号；不得宣称治愈率 |
| 家电/数码 | 能效/参数须与实际一致；「军工级」「航天级」无依据禁止 |

## 5. AIGC 与肖像
- AI 生成的写实人物图：按平台要求进行 AI 生成标识；不冒充真人实拍"买家秀"
- 不复刻可识别真人（明星、网红）面孔；不用未授权的他人品牌、IP、logo
- 不去除生成内容的来源标记/水印凭证

## 6. 白底图规则
见 `taobao-specs.md`；常见驳回原因：非纯白、有阴影底座、带文字/水印、主体太小、拼图、裁切不全。
