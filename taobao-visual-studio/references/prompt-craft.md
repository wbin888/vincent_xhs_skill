# Prompt 工艺

## §1 5 段式结构

每张图 Prompt = `[Style Lock]` + 以下 5 段：

| 段 | 内容 |
|---|---|
| 场景 Scene | 图型（主图/白底/详情信息屏）+ 背景 hex + 光线（方向、色温）+ 构图 + 角度景别 |
| 主体 Subject | 产品描述 + 材质 + 颜色 + 产品占比 + preserve 清单（用参考图时） |
| 关键细节 Details | 卖点、文案（「」包裹）、字号、字色 hex、标签/标注样式 |
| 用途 Use | 淘宝主图第 N 张 / 详情页第 N 屏，目标人群，手机端浏览 |
| 约束 Constraints | 留白比例、避让区、具体否定清单 |

中文或英文书写都可以；含中文文案时，文案本身保持中文并用「」包裹。

## §2 Campaign Style Lock（10 字段）

1. 视觉方向 2. 色板（2-3 主色 + 1 强调色，全 hex）3. 冷暖 4. 字体（标题 1 种 + 正文 1 种，禁第三种）
5. 背景系统 6. 光线系统 7. 布局系统（留白、圆角、标签样式）8. 图形元素样式（线宽/颜色）
9. 产品呈现（比例、材质表现）10. 禁止漂移项

示例：
```
【风格锁】清爽高级家居电商视觉；色板：背景 #FFFFFF / #F5F1E8 交替，标题 #2D2D2D，强调 #3A7D6B；中性偏暖 5000K 柔光，左上 45° 主光；标题现代无衬线粗体，正文无衬线常规；圆角 12px 浅色信息标签，1.5px 细线标注；产品材质真实、比例稳定；整套禁止更换色板、混用字体、随机背景、光线不一致。
```
多图任务：每张 Prompt 第一段**原样**粘贴，不改写、不缩短。重生单张也复用原锁。

## §3 生图铁律

1. **颜色写 hex**：白底 `#FFFFFF`，不写"白色"
2. **产品占比数字化**：白底图 60-80%；主图卖点图 35-50%；场景图 20-30%；详情信息屏 30-45%
3. **显式留白**：主图 ≥ 35%，场景/详情屏 ≥ 45%
4. **否定清单具体化**：`不要：多余文字、水印、虚假 logo、价格角标、额外的手、变形的产品、乱码文字、杂乱道具`
5. **淘宝避让**：`左上角与底部 15% 区域不放文字`（平台角标/价格叠加）
6. **中文文案**：用「」包裹；每屏 ≤ 50 字；复杂笔画字换简单同义字；写清字号（如标题 56px）
7. **文字兜底**：模型多次渲染错字 → 生成无字底图（写 `留出顶部 25% 纯色区域用于后期排字`），交付时注明需后期加字
8. **参考图 preserve**：`以参考图为产品唯一依据，保留：外形轮廓、颜色、logo 位置、材质纹理、包装文字；只改变背景与构图`
9. **一图一事**：一个 Prompt 不塞多个场景/多种风格

## §4 角度与景别

| 角度 | 写法 |
|---|---|
| 正面 3/4 | 3/4 前侧视角，展示正面与一侧 |
| 俯拍 90° | 正上方垂直俯拍 |
| 侧面 90° | 纯侧面轮廓 |
| 后 45° | 后侧 45°，展示背面细节 |
| 低角度仰拍 | 低机位仰拍，显得挺拔 |
| 高角度 45° | 45° 俯视桌面视角 |

景别：全景（占比 35-40%）/ 中景（45-50%）/ 特写（55-60%）/ 微距（浅景深纹理）。每张 Prompt 必须显式写角度词。

## §5 去 AI 感（生活场景/买家秀/模特）

- 写具体拍摄设备与纪实感：`手机实拍质感，iPhone 15 Pro，非专业棚拍`
- 加真实瑕疵：轻微噪点、皮肤毛孔、自然褶皱、生活痕迹
- 胶片色：`Kodak Portra 400 色调`
- 禁用词：perfect、flawless、stunning、hyper-realistic、8K masterpiece、完美无瑕
- 手部交互必须符合该品类真实用法（不要用奇怪姿势拿产品）

## §6 视觉自检清单（出图后逐张）

| 项 | 不通过的表现 |
|---|---|
| 产品一致 | 形状/颜色/logo/按键/包装文字跑偏 |
| 文字 | 错字、缺笔画、乱码、多出未要求的字（放大逐字核对） |
| AI 痕迹 | 塑料肤质、多指/少指、边缘融合、过度对称、背景超现实、光过于完美 |
| 风格 | 色板/字体/光线偏离 Style Lock |
| 画面独立 | 遮住文字后看不出这屏要表达什么 |
| 平台 | 白底不纯、主体太小/被裁、文字压角标区 |

一轮只改最严重的一项，重生该张。

## §7 六套风格预设（供用户选择）

| # | 名称 | 适合 | 关键词 |
|---|---|---|---|
| ① | 清透商拍 | 通用、日用、个护 | 白/浅灰底，柔光，干净明亮 |
| ② | 生活杂志 | 家居、食品、服饰 | 自然窗光，木纹/亚麻，暖调 |
| ③ | 极简高级 | 美妆、珠宝、数码 | 大留白，高反差，单色强调 |
| ④ | 活力爆款 | 快消、零食、大促 | 高饱和，粗体大字，撞色 |
| ⑤ | 暗调质感 | 男士、酒水、3C | 深色底，戏剧侧光，金属/玻璃反光 |
| ⑥ | 国风雅致 | 茶、文创、礼盒 | 宣纸米色，留白，朱红/黛青点缀 |

## §8 示例：详情页信息屏 Prompt

```
【风格锁】……（原样粘贴）
场景：电商详情页信息屏，竖版 2:3，背景 #F5F1E8，左上 45° 柔光 5000K；上下结构，高角度 45° 俯视。
主体：参考图中的保温杯（保留外形、颜色 #3A7D6B、杯身 logo 位置、磨砂质感），占画面 35%，位于下半部偏左。
关键细节：顶部主标题「早上装的热水 下午还烫嘴」56px #2D2D2D；右侧 3 个圆角标签「12 小时保温」「一键开盖」「杯口可伸手」各 26px #3A7D6B；杯口旁 1.5px 细线标注。
用途：淘宝详情页第 3 屏，面向通勤上班族，手机端浏览。
约束：留白 ≥45%；不要：额外文字、水印、价格、假 logo、温度计数值、杂乱道具、乱码。
```
